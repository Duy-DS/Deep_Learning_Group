# MLP – Thực nghiệm nhóm A

## Cài thư viện
```bash
pip install torch numpy pandas matplotlib
```

## Chạy
```bash
python experiment_a.py
```

## Cấu hình cố định
- Gaussian 2D: mu = [0, 0], C = [[0.3, -0.5], [-0.5, 2]]
- Số mẫu train: 200, 400, ..., 2000
- Validation độc lập: 500 mẫu; test độc lập: 100 mẫu
- MLP một tầng ẩn, 128 nơ-ron, sigmoid; SGD, learning rate 0.01
- Batch size 32, 100 epochs; 3 seeds: 17, 42, 2026
- Chỉ chọn checkpoint theo validation MSE; test chỉ dùng đánh giá sau cùng.

## Đầu ra
- `outputs/group_a_runs.csv`: mỗi dòng là một quy mô và seed, gồm MSE/MAE/RMSE, epoch tốt nhất, thời gian.
- `outputs/group_a_summary.csv`: trung bình và độ lệch chuẩn theo quy mô.
- `outputs/group_a_epoch_log.csv`: train/validation MSE theo epoch.
- `outputs/group_a_error_by_size.png`: sai số theo quy mô, trung bình ± độ lệch chuẩn.
- `outputs/group_a_convergence.png`: đường hội tụ validation MSE theo epoch.
- `checkpoints/*.pth`: trọng số tốt nhất theo validation cho từng lần chạy.

## Lưu ý đọc kết quả
Không ghi trước kết luận rằng sai số chắc chắn giảm. Chạy chương trình, xem bảng và đồ thị thực tế rồi mới nhận xét. Nếu validation/test error dao động hoặc không giảm đều, báo cáo điều đó và xem xét tính ngẫu nhiên, số epoch, learning rate và kiến trúc; không chọn cấu hình dựa trên test.
