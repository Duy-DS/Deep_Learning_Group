Đường dẫn tương đối được giải từ project root bằng pathlib.Path. Legacy keyword
API `train_config=`, `checkpoint_path=` và aliases `train_epoch`/`evaluate` được
giữ; `evaluate` chỉ còn validation-only. Cú pháp positional cũ
`Trainer(model, config, device, path)` không được hỗ trợ: dùng keyword legacy
hoặc API mới `Trainer(model, optimizer, criterion, device, ...)`.

Checkpoint lưu trên **strict minimum val_loss**, hòa giữ epoch sớm nhất.
Early Stopping dùng mốc significant improvement riêng với min_delta, dừng sau
patience lần không cải thiện. Sau fit nạp cả trạng thái model và optimizer tốt nhất,
model ở eval. History trả về chứa toàn run; history trong checkpoint chỉ tới best epoch.
Fit reset bookkeeping, **không** tự reset model/optimizer: run độc lập cần instance mới.
History lr ghi nhóm optimizer đầu tiên. Loss hỗ trợ scalar mean reduction.
