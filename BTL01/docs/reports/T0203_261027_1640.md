# Báo cáo hoàn thành Task T0203

## 1. Thông tin chung

- **Task ID:** T0203.
- **Tên task:** Khảo sát thống kê dữ liệu, vẽ 3D scatter và mặt cong Gaussian thật.
- **Bắt đầu:** 2026-10-27 16:28 +07:00.
- **Kết thúc kiểm tra chính:** 2026-10-27 16:40 +07:00.
- **Trạng thái:** Completed.

## 2. Mục tiêu Task

Triển khai class `Visualizer` để tạo bảng thống kê dữ liệu và hình PNG 300 DPI
có title, axis labels, legend/colorbar. Bổ sung notebook demo để tái mở nhanh
các artifact dữ liệu.

## 3. Các thay đổi đã thực hiện

| File | Thay đổi |
| :--- | :--- |
| `src/visualizer.py` | Tạo class `Visualizer` với `plot_data_distribution`, `plot_true_surface`, `build_summary_table`. |
| `outputs/figures/data_distribution_3d.png` | 3D scatter train/val/test, title, nhãn trục, legend, 300 DPI. |
| `outputs/figures/true_gaussian_surface_3d.png` | Mặt cong Gaussian thật trên grid 101 x 101, title, nhãn trục, colorbar, 300 DPI. |
| `outputs/tables/data_summary.csv` | Thống kê count, mean, std, min, max cho `x1`, `x2`, `y` theo từng split. |
| `notebooks/demo_exploration.ipynb` | Notebook demo đọc CSV, summary và nhúng hai hình đã sinh. |
| `README.md` | Cập nhật trạng thái T0201-T0203 và danh sách artifact dữ liệu/figure/table mới. |
