- **Task ID:** T0201.

- **Bắt đầu:** 2026-10-27 16:28 +07:00.
- **Kết thúc kiểm tra chính:** 2026-10-27 16:40 +07:00.
- **Trạng thái:** Completed.
- **Nhánh làm việc:** `feat/BTL01_T0201_T0202_T0203_finish`.

## 2. Mục tiêu Task

Triển khai class OOP `GaussianDataGenerator` để giữ tham số Gaussian 2D,
kiểm tra covariance SPD, tính nhãn mật độ chính xác theo công thức giải tích,
sinh tọa độ đều trong miền `[-2, 2] x [-4, 4]`, và cung cấp API tái sử dụng
cho các task dữ liệu/huấn luyện sau.

## 3. Các thay đổi đã thực hiện

| File | Thay đổi |
| :--- | :--- |
| `src/__init__.py` | Khởi tạo package `src` và export `GaussianDataGenerator`, `Visualizer`. |
| `src/data_generator.py` | Tạo `GaussianDataGenerator` với type hints, docstring, kiểm tra shape, symmetry, Sylvester, eigenvalues, inverse covariance, determinant và normalizer. |
| `experiments/generate_data.py` | Dùng generator để chạy workflow sinh dữ liệu T0201-T0203 từ `configs/baseline.yaml`. |

Các method chính đã triển khai: `compute_density`, `sample_features`,
`generate_dataframe`, `generate_splits`, `fixed_train_subset_indices`,
`validate_dataframe`.

```powershell
..\.venv\Scripts\python.exe scripts\verify_protocol.py
..\.venv\Scripts\python.exe -m compileall src experiments scripts
```
