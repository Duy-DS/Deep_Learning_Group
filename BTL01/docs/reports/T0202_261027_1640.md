- **Trạng thái:** Completed.

## 2. Mục tiêu Task

Tạo script tái lập được để sinh ba split độc lập bằng seed 42, lưu đúng
`data/train_full.csv`, `data/val.csv`, `data/test.csv`, giữ test set độc lập
và không dùng test cho huấn luyện/chọn checkpoint.

## 3. Các thay đổi đã thực hiện

| File | Thay đổi |
| :--- | :--- |
| `experiments/generate_data.py` | Tạo workflow đọc `baseline.yaml`, sinh split bằng `SeedSequence(42).spawn(3)`, ghi CSV UTF-8 không index với float format cấu hình. |
| `data/train_full.csv` | Sinh 2000 mẫu train đầy đủ. |
| `data/val.csv` | Sinh 200 mẫu validation độc lập. |
| `data/test.csv` | Sinh 100 mẫu test độc lập. |
| `outputs/tables/data_integrity_checks.csv` | Ghi audit row count, domain/formula validation và overlap giữa các split. |
| `outputs/tables/data_generation_manifest.json` | Ghi seed, RNG, tham số Gaussian, inverse covariance và SHA-256 các file dữ liệu. |

## 4. Kiểm thử & xác minh

Đã chạy:

```powershell

..\.venv\Scripts\python.exe -c "import pandas as pd; ..."
```
