# T0501-T0602 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement, execute, validate, visualize, and document experiments B and C for the BTL01 Gaussian-function approximation project.

**Architecture:** Extend the existing `ExperimentRunner` from single-trial execution to deterministic factor suites. Reuse one suite pipeline for B (hidden width) and C (hidden depth), writing per-run artifacts before aggregating mean/std summaries. Extend `Visualizer` with factor-error, train-validation-gap, loss-convergence, and depth-timing plots; keep model selection validation-only and use test only after all decisions are frozen.

**Tech Stack:** Python 3.10+, PyTorch, NumPy, Pandas, Matplotlib, PyYAML, `unittest`, existing project modules only.

**Spec:** `docs/project_charter/problem_specification_and_protocol.md`, `configs/baseline.yaml`, `configs/exp_specs.yaml`, and `AGENTS.md`.

## Global Constraints

- Use PyTorch only for model and training; do not add TensorFlow, Keras, scikit-learn MLP, AutoML, or high-level training wrappers.
- Preserve the fixed generated data: `train_full=2000`, `val=200`, `test=100`; do not regenerate it during B/C unless the manifest proves the same protocol and hashes.
- Use training seeds `[42, 100, 2026]`; seeds may affect model initialization and training shuffle only.
- Select checkpoints and hyperparameters using validation loss/MSE only; evaluate test metrics only in the final frozen phase.
- B uses train size `1000`, one hidden layer, widths `[1..10, 16, 32, 64]`, for `39` runs.
- C uses train size `1000`, hidden depths `[1..5]`, width `10` per layer, fixed-width and not parameter-matched, for `15` runs.
- Keep `tanh`, Adam, batch size `32`, learning rate `0.005`, deterministic settings, early stopping, checkpoint restore, and all other baseline values unchanged.
- Report MSE, RMSE, MAE for train/validation/test; aggregate with mean and sample standard deviation (`ddof=1`) over valid seeds.
- Training time starts immediately before the first epoch and ends after the final epoch/checkpoint write, with accelerator synchronization where configured.
- Every completed task requires a post-task report under `docs/reports/`; do not claim full-suite completion from smoke tests.

## Review Focus

- A run must not accidentally train on validation or test data, including through `Subset`, `ConcatDataset`, or reused loaders; add split metadata assertions in suite tests.
- A seed must not change the frozen data subset; test that B/C runs use the same prefix indices for all training seeds.
- A checkpoint must be the strict minimum validation loss, independent of `min_delta`; test that the restored model matches the saved checkpoint.
- A failed or non-finite run must be recorded as failed and excluded from summary statistics rather than silently dropped.
- Summary plots must use only persisted CSV metrics and include title, axis labels, legend, error bars where applicable, and at least 300 DPI.
