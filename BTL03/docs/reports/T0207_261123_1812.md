## 3. 🧪 DETAILED ACCEPTANCE FINDINGS

### A. Functional Implementation

Luồng tensor:

```text
(B,8,1,28,28)
→ reshape (B×8,1,28,28)
→ Conv/Pool: (B×8,64,14,14)
→ Conv/Pool: (B×8,128,7,7)
→ Conv/Pool: (B×8,256,3,3)
→ Flatten (B×8,2304)
→ reshape (B,8,2304)
→ LSTM1 (B,8,128)
→ LSTM2 (B,8,128) → last step (B,128)
→ Dropout → Linear (B,1)
```

| Layer | Params Keras | Params PyTorch |
|---|---:|---:|
| Conv 1→64 | 640 | 640 |
| Conv 64→128 | 73,856 | 73,856 |
| Conv 128→256 | 295,168 | 295,168 |
| LSTM 2304→128 | 1,245,696 | 1,245,696 |
| LSTM 128→128 | 131,584 | 131,584 |
| Dense 128→1 | 129 | 129 |
| **Tổng** | **1,747,073** | **1,747,073** |

PyTorch LSTM mặc định có hai bias 4H; Keras LSTM có một bias 4H. Model bỏ `bias_hh_l0` để giữ đúng 1,747,073 tổng tham số; bias hiệu dụng còn lại là `bias_ih_l0`. `init_weights_keras_style()` dùng Glorot input kernel, orthogonal recurrent kernel và forget-gate bias 1. Đây là parity số lượng tham số/khối; layout recurrent gate giữa framework cần lưu ý nếu sau này chuyển weights trực tiếp.
