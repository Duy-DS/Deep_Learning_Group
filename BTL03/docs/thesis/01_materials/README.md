# 01 — Materials (nguyên liệu)

Thư mục này lưu nguồn tham khảo và chỉ mục cần để biên soạn báo cáo; không phải nơi đặt draft hay PDF release.

- `samples/`: sample gốc của người dùng và phân tích style. Hai `.tex` mẫu phải giữ nguyên; chỉ tham khảo cấu trúc/trình bày.
- `templates/`: template legacy và `sample_style_v2/`. Template gốc READ-ONLY; template mới có version riêng.
- `evidence/`: manifest/outline trỏ tới report, CSV, config và source thật trong repo; không sao chép dataset, checkpoint hoặc logs nặng.
- `guidelines/`, `styles/`: chỉ tạo khi có quy định/cấu hình thực tế cần quản lý, không tạo placeholder rỗng.
