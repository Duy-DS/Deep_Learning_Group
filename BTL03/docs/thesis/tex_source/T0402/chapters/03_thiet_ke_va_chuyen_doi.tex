\chapter{Thiết kế hệ thống và chuyển đổi PyTorch}
\section{Kiến trúc OOP}
\begin{itemize}
\item \texttt{BaseMigratedModel}: forward contract, kiểm tra NCHW, parameter counters và feature hooks.
\item \texttt{BaseTrainer}: train/validation, callbacks, logger, checkpoint; validation dùng inference mode.
\item \texttt{seed\_everything(42)} và worker/generator helpers hỗ trợ reproducibility. T0106 lưu ý PYTHONHASHSEED cần đặt trước khi khởi tạo process để tác động hash seed của process hiện tại.
\item Callbacks có lifecycle, EarlyStopping, ModelCheckpoint và ReduceLROnPlateau.
\item \texttt{ExperimentLogger} ghi epoch CSV, master CSV 18 cột và SummaryWriter; \texttt{CheckpointManager} lưu state/metadata, mirror Drive chỉ khi mount root tồn tại.
\item YAML/runners/\texttt{src/train.py} cung cấp CLI dispatch; `--task all --smoke-test` là synthetic harness, không phải full training.
\end{itemize}
T0104 ghi logger smoke độc lập PASS; T0212 ghi SummaryWriter BLOCKED bởi protobuf/TensorBoard. Hai kết quả thuộc các runtime/mốc khác nhau, cần nêu đúng phạm vi.
