# Releases — báo cáo tổng kết BTL03

Chỉ lưu thành phẩm đã được nhóm biên dịch và duyệt. Mỗi release dùng thư mục phiên bản (ví dụ `v1.0/`) chứa:

- `BaoCao_TongKet_BTL03.pdf`: PDF đã xem trên Overleaf.
- `release_notes.md`: source snapshot/commit, thời điểm tạo, người duyệt, compiler/platform và các giới hạn đã biết.

Không chép PDF chưa duyệt, bản nháp, `.aux`, `.log`, `.fls`, `.fdb_latexmk` hoặc `.synctex.gz` vào release. Hiện chưa có PDF được duyệt; thư mục này chỉ là hướng dẫn, chưa phải release.
